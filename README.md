# 插件集成（Plugin Hub）

把侧栏里散落的插件面板收进同一个入口：侧栏只留「插件集成」一个图标，里面的页签就是各个插件自己的界面。本插件不含任何功能代码，也不复制别人的源码，插件装了就出现、卸了就消失。

## 功能

- **一个入口**：其它插件注册到侧栏的按钮会被收进集成页并隐藏，侧栏保持干净。
- **动态页签**：安装插件 → 页签立刻出现；停用/卸载 → 页签立刻消失，无需重启。
- **顺序稳定**：首次按插件自己的侧栏排序铺开，之后新装的插件一律追加在末尾，不会插队。
- **官方面板不动**：插件管理、自动化任务保持原位，不被收集也不被隐藏。
- **容错**：某个面板渲染失败只影响该页签，其余照常；无法内嵌的面板提供「单独打开」。

## 使用

1. 安装本插件（插件市场索引见下）。
2. 正常安装/启用任意带侧栏面板的插件。
3. 点侧栏「插件集成」，用顶部页签切换各插件界面。
